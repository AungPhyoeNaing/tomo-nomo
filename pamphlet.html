၁။ တိုမို (Tomo) ဆိုတာ ဘာလဲ?

AI Virtual Companion • ရေစက်ဆန်းစစ်စနစ်
စက္ကန့်ပိုင်းအတွင်း သုံးသပ်မည်

နာမည်နှင့် မွေးနေ့ ၂ ခု ထည့်သွင်းလိုက်ရုံဖြင့် တိုမို (Tomo) အမည်ရှိ AI စနစ်က နှစ်ဦးကြားရှိ စိတ်နေစိတ်ထား၊ ဓာတ်ကျမှု (Chemistry) နှင့် ဆက်ဆံရေး အားသာချက်/အားနည်းချက်များ ကို မြန်မာဘာသာဖြင့် အသေးစိတ် သုံးသပ်ဖတ်ရှုပေးမည့် စနစ်ဖြစ်ပါသည်။

A
သူငယ်ချင်း သို့မဟုတ် ချစ်သူစုံတွဲ ရွေးချယ်နိုင်ခြင်း:

Friends Mode (ခင်မင်သစ္စာရှိမှု) သို့မဟုတ် Couple Mode (အချစ်ရေး ဓာတ်ကျမှု) အလိုက် သီးသန့် တွက်ချက်ပေးပါသည်။

B
တိုမို ၏ စရိုက်ပုံစံ (Tone) ၃ မျိုး ရွေးချယ်နိုင်ခြင်း:

ချိုသာဂရုစိုက် (Sweet)၊ စနောက်သွက်လက် (Playful) သို့မဟုတ် လေးနက်ဆန်းကြယ် (Mystic) ပုံစံများ ရွေးချယ်နိုင်ပါသည်။

C
စိတ်ဝင်စားဖွယ် Match Score Gauge & ကတ်ပြား:

နှစ်ဦးကြား လိုက်ဖက်မှု ရာခိုင်နှုန်း (Gauge) နှင့် အကြံပြုချက်များကို အလှပုံရိပ်ဖြင့် ကြည့်ရှုသိမ်းဆည်းနိုင်ပါသည်။

App သွင်းစရာမလိုဘဲ Browser တွင် တိုက်ရိုက် စမ်းသပ်ကြည့်ရှုနိုင်ပါသည်။

၂။ နိုမို (Nomo) ဆိုတာ ဘာလဲ?

Real-Time Multiplayer Quiz • သူငယ်ချင်းဂိမ်း
Laptop ၂ လုံးဖြင့် အတူဆော့ကစားမည်

သူငယ်ချင်းနှစ်ဦး အချင်းချင်း မည်မျှအထိ သိနားလည်သလဲ ဆိုသည်ကို Laptop ၂ လုံးဖြင့် အချိန်နှင့်တပြေးညီ ချိတ်ဆက်ပြီး တစ်ဦး၏ အကြိုက်ကို အခြားတစ်ဦးက လိုက်လံခန့်မှန်းရသည့် အပြန်အလှန် Quiz ဂိမ်း ဖြစ်ပါသည်။

1
Room Code ဖြင့် အလွယ်တကူ ချိတ်ဆက်ခြင်း:

တစ်ဖက် Laptop မှ Room Code ဖန်တီးပြီး အခြား Laptop ထံ Link ပေးပို့ကာ ဂိမ်းခန်းထဲသို့ ဝင်ရောက်နိုင်ပါသည်။

2
မေးခွန်း ၁၀ ခုရွေးပြီး မိမိအဖြေမှန် သတ်မှတ်ခြင်း:

စားသောက်၊ Crush၊ အလွဲများထဲမှ မိမိကြိုက်နှစ်သက်ရာ မေးခွန်း ၁၀ ခုကို ရွေးချယ်ဖြေဆိုပေးရမည် ဖြစ်ပါသည်။

3
သူငယ်ချင်း ရွေးချယ်ထားမှုကို ခန့်မှန်းရမှတ်ယှဉ်ခြင်း:

သူငယ်ချင်း ရွေးထားသည်များကို မိမိက လိုက်လံဖြေဆိုပြီး မည်သူ ရမှတ်ပိုရသလဲ ယှဉ်ပြိုင်ကြည့်ရှုရမည် ဖြစ်ပါသည်။

Booth တွင် Laptop ၂ လုံးဖြင့် အပြိုင်စမ်းသပ် ကစားနိုင်ပါသည်။

Key Features, Technology Highlights & Live Demo Guide

Interactive Web Project

မေးခွန်းပေါင်း ၁၈၀ ကျော် (Category ၄ မျိုး)

လူငယ်များအကြိုက် ခေတ်မီအကြောင်းအရာများ

1. Food & Hangouts (စားသောက်/ဘဝ): မာလာရှမ်းကော Level၊ မနက်စာ ဘာစားမလဲ၊ လက်ဖက်ရည်ဆိုင် အလွဲများ
2. Crush & Dating (အချစ်ရေး/Crush): Crush ရှေ့မှ အလွဲများ၊ Date လုပ်ချိန် အလေ့အကျင့်၊ စိတ်ကူးယဉ်ပုံစံ
3. Memes & Trends (ခေတ်ပေါ်အလေ့အထများ): ဖုန်းအား ၁% မှ သွင်းသည့်စရိုက်၊ TikTok အလေ့အထများ
4. Friendship Roasts (စနောက်မေးခွန်းများ): မုန့်ဝယ်ကျွေးမည်ပြောပြီး ပိုက်ဆံအိတ်မေ့သည့် သူငယ်ချင်းအလွဲများ
လူငယ်များ လက်တွေ့ကြုံတွေ့ရသော အလွဲများကို ပျော်ရွှင်စွာ မေးမြန်းနိုင်ပါသည်။

အသုံးပြုထားသော နည်းပညာများ (Tech Stack)

Core Technologies Overview

UI
Frontend (မျက်နှာပြင်):

React 18 + Vite 5 + Tailwind CSS (မြန်ဆန်သွက်လက်သော User Interface)

WS
Real-Time Server (ချိတ်ဆက်မှု):

Node.js + Express + Socket.io (Laptop ၂ လုံး တိုက်ရိုက် ဂိမ်းကစားနိုင်ရန်)

AI
AI Reading (ဉာဏ်ရည်တု အကြံပြုချက်):

Google Gemini 3.1 Flash Lite API (မြန်မာဘာသာ သုံးသပ်ချက်များ ထုတ်ပေးရန်)

AU
Audio Engine (သီချင်းသံစဉ်):

Web Audio API (သီချင်းဖိုင်မလိုဘဲ တိုက်ရိုက်တီးခတ်သော Procedural Synth)

ခေတ်မီ Web နည်းပညာများကို ပေါင်းစပ်၍ တည်ဆောက်ထားပါသည်။

Booth တွင် ကိုယ်တိုင် စမ်းသပ်နည်း

Live Demonstration ၃ ဆင့်

အဆင့် ၁။ Tomo ကို အရင် စမ်းသပ်ခြင်း:

အမည်နှင့် မွေးနေ့ကို ထည့်သွင်းပြီး "Tomo ရဲ့ ဖတ်ရှုချက် ရယူမည်" ကို နှိပ်၍ သုံးသပ်ချက် ဖတ်ရှုပါ။

အဆင့် ၂။ Nomo ဂိမ်းကို Laptop ၂ လုံးဖြင့် ဆော့ခြင်း:

Booth ရှိ Laptop ၂ လုံးတွင် Room Code တစ်ခုထဲ ဝင်ကာ မေးခွန်း ၁၀ ခုကို အပြန်အလှန် ခန့်မှန်းဖြေဆိုပါ။

အဆင့် ၃။ ရလဒ်များ နှိုင်းယှဉ်ကြည့်ရှုခြင်း:

မည်သူက အချင်းချင်း ပိုမိုသိရှိသလဲဆိုသည်ကို Match Score ရမှတ်များနှင့်အတူ ကြည့်ရှုပါ။
